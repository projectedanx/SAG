# 002. Introduction of the Pluriversal Knowledge Capsule (PKC)

## Status
Accepted

## Context
When human 'Tacit Operational Friction' is injected into a deterministic Technical Specification (Topological Causal Sculpting), a mechanism is required to hold the ambiguity and contradiction in tension without averaging it out (Semantic Annihilation). We needed a serialized format to document this structural tension, aligned with the TACTILE_DIALECTICIAN protocol.

## Decision
We decided to implement the **Pluriversal Knowledge Capsule (PKC)** schema (`pluriversalCapsuleGenerator.ts`).
The PKC is a formalized JSON artifact that explicitly tracks:
- `Hickam_Orientation`: The foundational axiom alongside multi-causal vectors.
- `Contrastive_Delta`: The tension introduced by human operational friction (including the 'Golden Scar' multiplier).
- `Martensite_Metrics`: Structural strain, calculated 'Metabolic Cost', alignment drift (CFDI), and infomorphism mapping of inverse safety states.

## Consequences
- **Positive:** Mathematically preserves the structural tension ([∇]) and semantic conflicts ([⊗]) between pure AI generation and human constraint. Provides a verifiable, Zero-Entropy artifact compliant with JSON Schema Draft 2020-12.
- **Negative:** Increases the schema complexity of the `AppItem` object and requires strict mapping logic during the Zero-Entropy Code Emission phase.
